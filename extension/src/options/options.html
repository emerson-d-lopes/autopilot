Lantern

What the agent may do in this browser. These checks run inside the extension, so a client cannot bypass them.

Browser label

A name for this browser profile, shown by list_connected_browsers and usable with select_browser. Useful when several profiles are connected at once, since they otherwise differ only by id.

Permission mode

Blocked hosts

One host per line. A leading *. matches subdomains. Blocked hosts are refused for reading as well as acting.

Allowed hosts

Overrides the blocklist, for cases like a payment provider's sandbox.

Shortcuts

Named quick scripts, one per block. Run them with shortcuts_execute. A block is a first line id | name | description, then the script lines. Blocks are separated by a blank line.
